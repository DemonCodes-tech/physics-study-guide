            <h2 class="text-4xl font-bold text-[#1a1a1a] mb-4 border-b-2 border-[#b3b3ff] pb-2">Module 6: Circular Motion</h2>

            <p class="text-[#333333] text-lg mb-8 leading-relaxed">This section delves into the fascinating world of objects moving in a circular path. Understand the fundamental variables that describe this motion and the essential forces required to keep objects turning. The interactive calculator below provides a hands-on way to apply these principles to real-world scenarios, enhancing your understanding and retention.</p>

                        <ul class="list-disc list-inside space-y-3 pt-4">

                            <li><strong>Angular Displacement ($\Delta\theta$):</strong> The angle an object rotates around a central point, measured in radians. $x = r\theta$</li>

                            <li><strong>Angular Velocity ($\omega$):</strong> The rate at which angular displacement changes, indicating how fast an object is rotating. $\omega = \frac{\Delta\theta}{\Delta t}$ or $\omega = \frac{2\pi}{T}$</li>

                            <li><strong>Centripetal Acceleration ($a_c$):</strong> The acceleration directed towards the center of the circular path, responsible for changing the direction of velocity. $a_c = \frac{v^2}{r} = \frac{4\pi^2r}{T^2}$</li>

                            <li><strong>Centripetal Force ($F_c$):</strong> The net force exerted towards the center of the circle that causes an object to have centripetal acceleration. $F_c = ma_c = \frac{mv^2}{r}$</li>

                        </ul>

            <p class="text-[#333333] text-lg mb-8 leading-relaxed">This section introduces Newton's Law of Universal Gravitation, a fundamental principle describing the attractive force between any two masses. The interactive chart below visualizes the inverse square law, demonstrating how gravitational force diminishes rapidly with increasing distance.                             <li><strong>Newton's Law of Universal Gravitation:</strong> Every particle attracts every other particle with a force proportional to the product of their masses and inversely proportional to the square of the distance between their centers. $F_g = \frac{Gm_1m_2}{r^2}$</li>

                            <li><strong>Gravitational Field ($g$):</strong> A region where a mass experiences a force due to gravity, often referred to as gravitational acceleration. $g = \frac{GM}{r^2}$</li>

                            <li><strong>Gravitational Constant ($G$):</strong> A universal constant with a value of approximately $6.67 \times 10^{-11}~N \cdot m^2/kg^2$.</li>

            <h2 class="text-4xl font-bold text-[#1a1a1a] mb-4 border-b-2 border-[#b3b3ff] pb-2">Module 8: Rotational Motion & Equilibrium</h2>

            <p class="text-[#333333] text-lg mb-8 leading-relaxed">This module explores the dynamics of rotational motion, including the concept of torque, which causes rotation, and moment of inertia, an object's resistance to angular acceleration. Furthermore, it delves into the conditions required for an object to achieve rotational and translational equilibrium, ensuring stability. Engage with the interactive tools to build an intuitive understanding of these crucial concepts.</p>

        

            <div class="space-y-8">

                 <!-- Accordion: Key Concepts -->

                <div class="bg-white rounded-xl shadow-xl hover:shadow-2xl transition duration-300 ease-in-out">

                    <button class="accordion-button flex justify-between items-center w-full p-5 font-semibold text-xl text-left bg-[#e6e6ff] rounded-xl hover:bg-[#e6e6ff]/70 transition duration-200 ease-in-out focus:outline-none">

                        <span>Key Concepts & Formulas</span>

                        <span class="transform transition-transform duration-300 text-[#0000ff]">&#9662;</span>

                    </button>

                    <div class="accordion-content px-5 pb-5 text-[#333333] leading-relaxed">

                        <ul class="list-disc list-inside space-y-3 pt-4">

                            <li><strong>Torque ($\tau$):</strong> The turning effect of a force about an axis of rotation. $\tau = Fr \sin\theta$. It's maximized when the force is perpendicular ($90^{\circ}$) to the lever arm.</li>

                            <li><strong>Moment of Inertia ($I$):</strong> The rotational equivalent of mass, representing an object's resistance to angular acceleration. Its value depends on both mass and how that mass is distributed relative to the axis of rotation. (e.g., $I=mr^2$ for a thin hoop, $I=½mr^2$ for a solid disk/cylinder)</li>

                            <li><strong>Newton's Second Law for Rotational Motion:</strong> States that the net torque on an object is equal to its moment of inertia multiplied by its angular acceleration. $\tau_{net} = I\alpha$</li>

                            <li><strong>Equilibrium:</strong> A state where an object has no net force (translational equilibrium) and no net torque (rotational equilibrium) acting on it. For rotational balance: $\tau_{clockwise} = \tau_{anticlockwise}$</li>

                        </ul>

                    </div>

            function calculateTorque() {

            function updateSeesaw() {

                const mass1 = parseFloat(m1.value);

                const dist1 = parseFloat(d1.value);

                const mass2 = parseFloat(m2.value);

                const dist2 = parseFloat(d2.value);

                    torqueRightEl.textContent = '-';

                    rightMassEl.textContent = `${isNaN(mass2) ? '-' : mass2}kg`;

                    seesawBeam.style.transform = `rotate(0deg)`;

                    balanceStatus.textContent = "Enter valid numbers.";

                    balanceStatus.className = "mt-8 text-center text-xl font-bold p-5 rounded-xl shadow-md bg-yellow-100 text-yellow-800";

                    return;

                const netTorque = torqueRight - torqueLeft;

                

                // Update mass labels on the seesaw

                leftMassEl.textContent = `${mass1}kg`;

                rightMassEl.textContent = `${mass2}kg`;


                // Position masses relative to beam length

                const beamWidthPercent = 80; // from CSS w-3/4 on md, means 75% for full width. For 80% on beam, use actual value here

                const beamHalfLength = (beamWidthPercent / 2) / 100; // Half length of beam in ratio to its parent container width


                // Calculate positions, scaling distances to fit within the visual beam

                // Assuming max practical distance on one side is about 2.5m for visualization, scale dist1/dist2 to that.

                const maxDisplayDistance = Math.max(dist1, dist2, 2.5); // Use a baseline to prevent extreme jumps or tiny moves

                

                // Left mass is relative to the center, shifted left. Right mass is relative to center, shifted right.

                // Convert percentage to actual pixels if needed, but relative calc is better.

                // We want -40% to +40% relative to center for the mass positions on the beam

                // Scale distance based on max possible slider value for full range

                const leftPos = - (dist1 / maxDisplayDistance) * (beamHalfLength * 100); 

                const rightPos = (dist2 / maxDisplayDistance) * (beamHalfLength * 100); 


                // Ensure masses don't go off the end visually for larger distances

                leftMassEl.style.left = `calc(50% + ${leftPos}% - 32px)`; // 32px is half of w-16 mass width

                rightMassEl.style.left = `calc(50% + ${rightPos}% - 32px)`;

                seesawBeam.style.transform = `rotate(${tiltAngle}deg)`;


                if (difference < (0.05 * g_constant)) { // Small threshold for balance

                    balanceStatus.textContent = "Balanced!";

                    balanceStatus.className = "mt-8 text-center text-xl font-bold p-5 rounded-xl shadow-md bg-[#d4edda] text-[#155724]"; // Custom green for balance

                    balanceStatus.textContent = "Tilted Clockwise!";

                    balanceStatus.className = "mt-8 text-center text-xl font-bold p-5 rounded-xl shadow-md bg-[#ffe6e6] text-[#cc0000]"; // Custom red for tilt

                    balanceStatus.className = "mt-8 text-center text-xl font-bold p-5 rounded-xl shadow-md bg-[#ffe6e6] text-[#cc0000]"; // Custom red for tilt

                }

            }
